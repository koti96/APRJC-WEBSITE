# APRJC Institutional Website

A responsive front-end web application designed for **APRJC N Sagar**. This project digitizes institutional information, providing an accessible and user-friendly interface for students and parents to access details about academics, facilities, and admissions.

## 🚀 Features
- **Responsive Design:** Optimized for viewing on desktops, tablets, and mobile devices.
- **Intuitive Navigation:** Structured sections for Academics, Facilities, and Admissions.
- **Clean UI:** Custom CSS styling for a professional and consistent visual identity.
- **Interactive Elements:** Basic JavaScript implementation for enhanced user interaction.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure of the webpages.
- **CSS3:** Custom styling and responsive layouts.
- **JavaScript:** Client-side interactivity.
